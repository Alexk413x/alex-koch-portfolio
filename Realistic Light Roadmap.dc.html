REALISTIC LIGHT · ROADMAP
CRT LAB · FIXTURE SIMULATION NOTES
v0 · DRAFT
Scratchpad for making the fixture read as a physically believable light. The dimmer + color-temp controls exist but aren't yet combined into one coherent lighting model. Below: what's live, and the ordered plan to close the realism gaps.
APPROACH
This lab is a static test-bed — a controlled environment for dialing in a specific look per situation. Animation comes later; right now static slider positions are exactly what we want.
— A saved set of all slider positions = one scenario (a "look"). Build a library of these first.
— Realistic animation later = interpolating between saved scenarios, not new render code.
— Before any drastic change: inventory what each control already does and why it exists. Understand first, refactor second.
— Keep this lab simple. Add depth through scenarios + tuning, not by complicating the base render.
CURRENT BEHAVIOR
LIVE
Dimmer maps to a piecewise brightness multiplier (llvl), applied as a linear CSS brightness(). Sub-25% zone simulates tube strike/warm-up (bright ends, dark middle).
PLANNED — REALISM GAPS
01
Perceptual brightness curve
Replace the linear brightness() mapping with a gamma / eased curve (≈ lvl^2) so low dimmer settings actually look dim instead of ~70%. Removes the perceptual over-brightness at the low end.
02
Temp × dimmer warm-shift KEY
Combine the TEMP slider with the dimmer: as the light dims, pull effective color temperature warmer (toward amber/red), the way real sources do. TEMP sets the "full-power" white point; dimmer biases it down from there. This is the single biggest realism win.
03
Superlinear glow falloff
Bloom/halo currently scales linearly with the dimmer (glowRaw ∝ d). Physically the halo falls off faster than the source — square it (or higher) so low dimmer kills the halo before the tube face goes dark.
04
Smooth the dimmer curve
Remove the visible kinks at the 0.25 / 0.5 breakpoints — one continuous curve for lvl + strike blend rather than three linear segments.
05
Flicker coupling at low power
Tie flicker amplitude to low dimmer / low health so a struggling tube reads as flickery and slightly pink, like a real dying fluorescent.
OPEN QUESTIONS
— Should TEMP be an absolute white point, or an offset the dimmer bends from?
— How far warm should full-dim go before the tube cuts out (fluorescents don't dim to zero gracefully)?
— Do the caps / wall wash follow the same warm-shift, or stay neutral metal?
