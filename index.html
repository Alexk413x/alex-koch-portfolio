Best on desktop. These are instruments laid out at around 1560×1100. On a narrow screen the control panel folds away behind a CONTROLS button so the tube gets the screen to itself, but the control density is still built for a large window. The WebGL build is demanding; if it struggles, RENDER SCALE in its panel is the lever. First load pulls React and Babel from a CDN, so give it a moment.
